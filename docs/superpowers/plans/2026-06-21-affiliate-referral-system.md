# Affiliate Referral System — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a lightweight affiliate referral system where anyone can register, get a unique tracking link, and earn a one-time 20% commission when their referred client makes their first payment.

**Architecture:** New `affiliates/` module in the backend (following the `leads/` pattern: domain → application → infrastructure) and a new `indicador/` route group in the frontend. Attribution flows via a cookie set by the landing page, stored on `LandingLead`, then carried to `Organization.referralCode` at account creation time. The `PaymentReceivedHandler` triggers commission creation when `payment.cycleNumber == 1`.

**Tech Stack:** Java 21 + Spring Boot 3 + JPA/Hibernate + Lombok + Flyway (backend); Next.js app router + TypeScript + Bootstrap 5 + js-cookie (frontend); JUnit 5 + Mockito (backend tests); Jest + ts-jest (frontend tests).

## Global Constraints

- Backend package root: `com.brainbyte.easy_maintenance`
- All new backend classes use Lombok (`@Data`, `@Builder`, `@RequiredArgsConstructor`, etc.)
- Migration naming: `V{N}__snake_case_description.sql` — next free numbers are **V72** and **V73**
- Public endpoints (no auth): `/easy-maintenance/api/v1/landing/**`, `/easy-maintenance/api/v1/affiliates/**`
- Admin endpoints use existing admin security filter — same pattern as `CommissionAdminController` should be under `/easy-maintenance/api/v1/admin/**`
- Frontend public routes: add `/indicador` to `PUBLIC_ROUTES` in `src/middleware.ts`
- Commission = `planPrice * commissionRate`, both values snapshotted at conversion time
- First payment detected by `payment.getCycleNumber() == 1`
- Affiliate code: 6 uppercase alphanumeric chars (A–Z, 0–9), generated by the service

    @Column(nullable = false, length = 20)
    @Builder.Default
    private AffiliateStatus status = AffiliateStatus.ACTIVE;

    @CreationTimestamp

}

    private static final String BASE_URL = "https://easymaintenance.com.br/landing?ref=";
    private static final String CHARS = "ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789";
    private static final int CODE_LENGTH = 6;
    private static final BigDecimal DEFAULT_COMMISSION_RATE = new BigDecimal("0.2000");

    private final AffiliateRepository affiliateRepository;
    private final ReferralCommissionRepository commissionRepository;
    private final LandingLeadRepository leadRepository;

    @Transactional
    public AffiliateResponse createAffiliate(CreateAffiliateRequest request) {
        if (affiliateRepository.existsByEmail(request.email())) {
            throw new IllegalArgumentException("E-mail já cadastrado como afiliado.");
        }
        String code = generateUniqueCode();
        Affiliate affiliate = Affiliate.builder()
                .name(request.name())
                .email(request.email())
                .whatsapp(request.whatsapp())
                .code(code)
                .commissionRate(DEFAULT_COMMISSION_RATE)
                .build();
        Affiliate saved = affiliateRepository.save(affiliate);
        log.info("[Affiliate] New affiliate registered: code={}, email={}", code, request.email());
        return toResponse(saved);
    }

    public Affiliate findByCode(String code) {
        return affiliateRepository.findByCode(code)
                .orElseThrow(() -> new IllegalArgumentException("Afiliado não encontrado: " + code));
    }

    public AffiliateDashboardResponse getDashboard(String code) {
        Affiliate affiliate = findByCode(code);
        var leads = leadRepository.findAllByAffiliateCode(code);
        var commissions = commissionRepository.findAllByAffiliateId(affiliate.getId());

        long converted = commissions.size();
        BigDecimal pending = commissions.stream()
                .filter(c -> c.getStatus() == CommissionStatus.PENDING)
                .map(c -> c.getCommissionAmount())
                .reduce(BigDecimal.ZERO, BigDecimal::add);
        BigDecimal paid = commissions.stream()
                .filter(c -> c.getStatus() == CommissionStatus.PAID)
                .map(c -> c.getCommissionAmount())
                .reduce(BigDecimal.ZERO, BigDecimal::add);

        List<ReferralLeadResponse> leadList = leads.stream()
                .map(l -> {
                    boolean isConverted = commissions.stream()
                            .anyMatch(c -> c.getOrganizationId() != null);
                    return new ReferralLeadResponse(maskEmail(l.getEmail()), isConverted ? "CONVERTED" : "LEAD", l.getCreatedAt());
                })
                .collect(Collectors.toList());

        return new AffiliateDashboardResponse(
                affiliate.getName(), affiliate.getCode(),
                BASE_URL + affiliate.getCode(),
                leads.size(), converted, pending, paid, leadList);
    }

    public Optional<Affiliate> suggestForEmail(String email) {
        return leadRepository.findFirstByEmailAndAffiliateCodeIsNotNull(email)
                .flatMap(lead -> affiliateRepository.findByCode(lead.getAffiliateCode()));
    }

    private AffiliateResponse toResponse(Affiliate a) {
        return new AffiliateResponse(a.getId(), a.getName(), a.getEmail(),
                a.getCode(), BASE_URL + a.getCode(), a.getCommissionRate());
    }

    private String generateUniqueCode() {
        SecureRandom rng = new SecureRandom();
        String code;
        do {
            StringBuilder sb = new StringBuilder(CODE_LENGTH);
            for (int i = 0; i < CODE_LENGTH; i++) sb.append(CHARS.charAt(rng.nextInt(CHARS.length())));
            code = sb.toString();
        } while (affiliateRepository.findByCode(code).isPresent());
        return code;
    }

    private String maskEmail(String email) {
        if (email == null || !email.contains("@")) return "***";
        String[] parts = email.split("@");
        String local = parts[0];
        String domain = parts[1];
        if (local.length() <= 2) return local.charAt(0) + "***@" + domain;
        return local.substring(0, 2) + "***@" + domain;
    }
}

            return null;

                .planName(planName)

                .commissionRate(affiliate.getCommissionRate())
                .commissionAmount(amount)
                .build();
        ReferralCommission saved = commissionRepository.save(commission);
        log.info("[Commission] Created: affiliateId={}, orgId={}, amount={}",
                affiliate.getId(), organizationId, amount);
        return saved;
    }

    public ReferralCommission markAsPaid(Long commissionId) {
        ReferralCommission c = commissionRepository.findById(commissionId)
                .orElseThrow(() -> new EntityNotFoundException("Comissão não encontrada: " + commissionId));
        c.setStatus(CommissionStatus.PAID);
        c.setPaidAt(Instant.now());
        return commissionRepository.save(c);

                            c.getCommissionRate(), c.getCommissionAmount(),

"use client";

import { useState } from 'react';
import Link from 'next/link';
import Logo from '@/components/Logo';
import { api } from '@/lib/apiClient';

interface AffiliateResponse {
  code: string;
  name: string;
  link: string;
  commissionRate: number;
}

export default function AffiliateRegistrationPage() {
  const [form, setForm] = useState({ name: '', email: '', whatsapp: '' });
  const [loading, setLoading] = useState(false);
  const [result, setResult] = useState<AffiliateResponse | null>(null);

      </nav>

                  <div className="mb-3">
                    <label className="form-label fw-semibold">Nome completo</label>
                    <input name="name" type="text" className="form-control"
                      placeholder="João Silva" required
                      value={form.name} onChange={handleChange} />
                  </div>
                  <div className="mb-3">
                    <label className="form-label fw-semibold">E-mail</label>
                    <input name="email" type="email" className="form-control"

                      value={form.email} onChange={handleChange} />

                    <label className="form-label fw-semibold">WhatsApp</label>

                  <div className="display-4 mb-3">🎉</div>

```tsx
// easy-maintenance-web/src/app/private/admin/affiliates/page.tsx
"use client";

import { useEffect, useState } from 'react';
import { api } from '@/lib/apiClient';

interface Commission {
  id: number; affiliateName: string; affiliateEmail: string; affiliateWhatsapp: string;
  organizationId: number; planName: string; planPrice: number;
  commissionAmount: number; status: string; paidAt: string | null; createdAt: string;
}

export default function AdminAffiliatesPage() {
  const [commissions, setCommissions] = useState<Commission[]>([]);
  const [loading, setLoading] = useState(true);
  const [filter, setFilter] = useState<'ALL' | 'PENDING' | 'PAID'>('ALL');

  const load = () => {
    setLoading(true);
    api.get<Commission[]>('/admin/affiliates-commissions/commissions')
      .then(setCommissions)
      .finally(() => setLoading(false));
  };

  useEffect(() => { load(); }, []);

  const markPaid = async (id: number) => {
    if (!confirm('Confirmar pagamento do PIX?')) return;
    await api.patch(`/admin/affiliates-commissions/commissions/${id}/pay`);
    load();
  };

  const formatCurrency = (v: number) =>
    new Intl.NumberFormat('pt-BR', { style: 'currency', currency: 'BRL' }).format(v);

  const filtered = commissions.filter(c => filter === 'ALL' || c.status === filter);
  const totalPending = commissions
    .filter(c => c.status === 'PENDING')
    .reduce((sum, c) => sum + c.commissionAmount, 0);

  return (
    <div className="p-4">
      <div className="d-flex justify-content-between align-items-center mb-4">
        <div>
          <h1 className="h4 fw-bold mb-1">Comissões de Afiliados</h1>
          <p className="text-muted mb-0">
            Total a pagar: <strong className="text-warning">{formatCurrency(totalPending)}</strong>
          </p>
        </div>
        <div className="btn-group">
          {(['ALL', 'PENDING', 'PAID'] as const).map(f => (
            <button key={f} onClick={() => setFilter(f)}
              className={`btn btn-sm ${filter === f ? 'btn-primary' : 'btn-outline-secondary'}`}>
              {f === 'ALL' ? 'Todas' : f === 'PENDING' ? 'Pendentes' : 'Pagas'}
            </button>
          ))}
        </div>
      </div>

      {loading ? (
        <div className="text-center py-5"><div className="spinner-border text-primary" /></div>
      ) : filtered.length === 0 ? (
        <div className="text-center text-muted py-5">Nenhuma comissão encontrada.</div>
      ) : (
        <div className="table-responsive">
          <table className="table table-hover align-middle">
            <thead className="table-light">
              <tr>
                <th>Afiliado</th>
                <th>WhatsApp</th>
                <th>Org ID</th>
                <th>Plano</th>
                <th>Valor plano</th>
                <th>Comissão (20%)</th>
                <th>Status</th>
                <th>Data</th>
                <th></th>
              </tr>
            </thead>
            <tbody>
              {filtered.map(c => (
                <tr key={c.id}>
                  <td>
                    <div className="fw-semibold">{c.affiliateName}</div>
                    <div className="small text-muted">{c.affiliateEmail}</div>
                  </td>
                  <td><a href={`https://wa.me/55${c.affiliateWhatsapp.replace(/\D/g,'')}`}
                    target="_blank" rel="noopener" className="text-success">{c.affiliateWhatsapp}</a></td>
                  <td className="text-muted small">{c.organizationId}</td>
                  <td>{c.planName}</td>
                  <td>{formatCurrency(c.planPrice)}</td>
                  <td className="fw-bold">{formatCurrency(c.commissionAmount)}</td>
                  <td>
                    <span className={`badge bg-${c.status === 'PAID' ? 'success' : 'warning text-dark'}`}>
                      {c.status === 'PAID' ? 'Pago' : 'Pendente'}
                    </span>
                    {c.paidAt && (
                      <div className="small text-muted">{new Date(c.paidAt).toLocaleDateString('pt-BR')}</div>
                    )}
                  </td>
                  <td className="text-muted small">{new Date(c.createdAt).toLocaleDateString('pt-BR')}</td>
                  <td>
                    {c.status === 'PENDING' && (
                      <button className="btn btn-success btn-sm rounded-pill px-3"
                        onClick={() => markPaid(c.id)}>
                        Marcar pago
                      </button>
                    )}
                  </td>
                </tr>
              ))}
            </tbody>
          </table>
        </div>
      )}
    </div>
  );
}
```
